# Code Sketch Level Standard

为每个页面选择一个级别，并在页面设计决策中记录理由。级别决定证据强度，不改变语义合同与 `layout-spec.yaml` 的必需性。

## Full

适用于核心路径、新颖交互、复杂状态/滚动/响应式结构或高风险页面。要求完整生产骨架、关系测试、确定性截图和独立 Code Sketch Review。

## Lightweight

适用于常规页面和已知组件组合。要求生产骨架与关系测试；仅在风险、系统行为或结构歧义需要时截图并独立审阅相应证据。

## Reuse

适用于批准模式的直接复用。记录批准来源与 delta；只有结构事实变化时才重新运行完整结构审阅，否则验证 delta 与受影响测试。

不得用低风险级别跳过状态、无障碍、滚动 owner、断点或系统避让合同。级别不授权 UX/UI Lead 写代码，也不允许 producer 自审。
