# 角色骨架与绑定

建立可由动画师稳定控制、可按目标形态变形、并能可靠导入游戏的角色骨架与绑定合同。

执行前阅读[公共执行协议](../app-creator-workflow/references/professional-execution.md)。以下共用步骤不能跳过所选原生适配规定的操作顺序、资源格式与平台边界；必要的用户确认按协议执行。

## 输入

- 角色模型/部件与目标视图；动作范围、极限姿势和变体；目标骨数/性能预算；导入骨架与动画消费端。

## 共用操作步骤

1. 冻结角色关节、可变形部位、可替换部件、变体身份和目标动作；列出必须到达的极限姿势及容易穿插的部位。
2. 明确2D骨骼或3D骨架路线。2D需确定骨骼树、插槽、网格切片、遮挡顺序与贴图变体；3D需确定骨骼层级、关节朝向、命名和变换空间。
3. 构建最小控制器并测试静止、极限弯曲、旋转和动作衔接；检查权重/网格畸变、遮挡穿插、根运动和关节翻转。
4. 锁定骨骼映射、控制器/约束、蒙皮、部件锚点、导出单位与版本；分别记录模型源文件和引擎导入资源之间的身份关系。
5. 在动画制作方交接前用代表动作回读真实导出结果，核对骨骼路径、变形质量、变体兼容、资源体积和运行预算。
6. 提交骨架图、命名和映射约定、极限姿势结果、剩余变形问题与对应动画/引擎验证责任人。

## 关键边界

- 2D骨架和3D蒙皮结构不可互换；只有Unity适配提供本仓库的两种原生绑定专门模式。
- 绑定通过仅说明技术可用，不代表动作表现或角色美术获批。

## 交付

- 角色绑定合同、骨架/插槽映射、代表姿势回归、导出回读证据和专业问题清单。
