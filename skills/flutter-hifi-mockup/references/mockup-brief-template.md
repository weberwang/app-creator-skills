# Flutter 可编辑设计输入模板

按需在已有需求和任务记录中整理输入，信息足够时直接按 [Figma App 设计流程](../../app-ui-layout/references/figma-app-design.md)制作方向，无需先请用户批准文字方案。仅设计提案不强制先建设运行工程；正式实现仍须确认完整 V1 模块方案。

## 当前页面与约束

复用[共同设计依据](../../app-asset-workflow/references/interface-intent.md#design-basis)，局部修改仅补受影响内容；在已有任务记录中说明有依据的方向与代价，不新增审批。

- 目标用户、主要任务、使用情境、页面与实际导航：
- 真实内容、必要文案、关键状态和期望交互：
- 主要操作顺序、使用压力及关键异常，已有／拟新增／待验证能力：
- 定位对应的信息层级、可读性、构图与一致性原则及来源，关键方案取舍：
- 已确认业务事实、功能、无障碍、平台与用户锁定品牌要求：
- 目标平台、视口、方向、语言、文字倍率和适用系统区域：
- 可探索的结构、布局、字体、配色、留白、组件形态和内容呈现：
- 已有代码和组件中值得复用的功能与实现条件：
- 用户明确要求忠实还原现有页面时所提供的依据：

不增加无关功能、虚构数据、装饰面板或营销文案；组件、图标、设计系统按目标体验适用性复用，不适合时可制作专属组件。

## 候选与冻结

生图前按[制作输入与发送前检查](../../app-asset-workflow/references/style-and-production.md#生成前约束)把适用分析转成实际提示词；记录真实发送原文、设计选择与来源到现有生成记录，不把本模板或后台工程规格整份送入画面。交付前的主任务与一个适用异常推演并入原有单次审查，不能据此自动看图或代写视觉通过。

首次定调或实质改版默认先由 imagegen 生成一张专业效果图，用户选稿后忠实重建可编辑 Figma；只有用户明确要求比较时才按指定数量制作多方向，保持同任务、主要内容及比较条件并体现实质差异。局部增量可复用有效方向。展示实际效果图，由用户确认或明确选择／组合；原图确认及忠实重建授权有效时，节点核对后直接提取 V3，不重复确认重建预览，再扩展其余页面和关键状态。

- 候选身份、实际效果图、提示词、生成来源、版本和 SHA-256：
- 忠实重建授权消息、Figma fileKey、nodeId、节点链接及转换关系：
- 目标状态、视口、语言及文字倍率：
- 原图确认与实际重建预览路径、SHA-256、是否人工检查（分别记录）：
- 用户真实选择消息与适用范围：
- Figma 结构采集、还原交接与正式消费记录的控制器引用：

V3 可直接复用所选节点已表达的组件、层级和布局，不重画草图或拆解图并重复确认；V4 才试接真实组件和实际独立素材。图层保持可编辑，文字、组件、实例、矢量与自动布局按适用性使用，变量按真实需要提供并实际绑定；无需变量的简单稿不凑三类 token。独立插画、照片和角色等按需生成或复用；不得将整页图片冒充可编辑设计。

生图工具、Figma 工具或额度不足时如实说明受阻步骤，不伪称已有产物。有效已确认且目标未变化的原图可复用；其他路线记录明确用户消息及范围。默认人工检查设计稿及运行截图，未经明确授权不分析或代写视觉 PASS，也不自动付费、购买素材、发布或运行真机。
