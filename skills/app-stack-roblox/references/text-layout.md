# Roblox 文本与布局

用户可见文本遵守[公共文案原则](../../app-domain-toolkit/references/ui-copy-principles.md)，确认其语言来源、真实使用的 GUI 文本组件、可用字体/字体资产及支持的脚本。动态数值、本地化和无障碍名称绑定真实数据和控件，不能把内部 GDD 或验收字段显示给玩家。

依据当前项目文字与字体配置选择 Roblox 原生布局、换行和缩放能力；固定宽度、最小阅读尺寸、长短代表值、支持的语言及文本溢出方式按已确认合同确定。组件配置需用当前版本实际能力验证，不以 `TextScaled`、裁切或截图上出现文字代替最小阅读尺寸检查。

文字相对其真实容器、图标或已确认参照停靠；父 `UIListLayout`/`UIGridLayout` 排布时不再由文字脚本写入位置。按轴分别记录 `UDim2`、布局或 `AutomaticSize` 的尺寸职责及真实组件参数；文本内容变化不得偷偷改变另一套静态布局。

在项目已支持的视口、系统界面/安全区与输入条件下检查长短内容和交互命中；目标屏幕截图由用户人工检查可读性、截断与遮挡。未运行的设备、未完成的本地化和用户未确认的显示分别记录。
