# Roblox 验证与交付

## 技术结果与实际运行

证据记录当前工作项、实际项目内源快照、Studio 和 Place 身份、对象、阶段、上下文、工具结果及其实际文件引用。`Edit` 是编辑器正式源，`Client` 与 `Server` 是播放上下文；运行时对象、控制台状态和本地离线 Schema 校验不能冒充正式文件保存或实际运行。

具体原生字段与校验由 [Roblox 领域证据合同](../../roblox-domain-contracts/references/domain-validation.md)规定。工程记录绑定所用源、读取与测试结果；V1、MODULE 和 INTEGRATION 中需要实际运行的行为留存真实 Client/Server 记录；V2–V5 的结构、资源、运行及人工确认按本对象的原生合同和公共门分别处理。采集/校验脚本仅校验提交材料，不能主动开启 Studio 或证明未发生的调用。

先查询现有实例和状态，按实际目标复用；不得关闭用户已有 Studio 或在无法确认归属时停止会话。选择工具前核对 `studio_id`、DataModel 类型和真实参数。已有试玩/运行实例的复用范围不明确时，先核对其目标与状态，不覆盖正式编辑内容；脚本或启动可能触发的真实外部写入按实际动作授权。

按任务选择 Luau 规则边界、Server/Client 交互、对象输入/命中、资源实际加载、失败/恢复与清理；多人功能检查重复/非法/迟到请求、共享状态及适用的网络条件。Studio 的客户端/服务器、多客户端、设备及网络模拟分别记录配置和覆盖，不把模拟当作真机、线上、真实服务或全部设备通过。[Studio 测试模式](https://create.roblox.com/docs/studio/testing-modes)

当前 Studio 对同 Experience 的 `TeleportAsync` 测试以实测版本及官方能力为准，跨 Experience、生产服务器身份和真实线上发布单独记录。无明确权限不启用真实 DataStore、网络、上传、付费或发布；这些仍按现有工作项的 action/effects 控制，不因为工具名称是 `execute_luau` 就默认为纯本地。使用测试替身时说明边界。

## 视觉与交付

V3 检查真实实例父子关系、位置参照、空间、大小、层序、输入和消费者；V4 确认正式源、资源引用和适用的审核/加载信息；V5 用正式组合检查真实交互和生命周期，并为用户提供截图或片段及检查点。截图默认只由用户人工判断；未经明确要求不自动分析截图或将插件 playtest 子代理的视觉描述当成用户确认。

屏幕 GUI 的 V3 先冻结 UDim2、AnchorPoint、列表或网格及双轴尺寸控制；V4 回读保存后的 Edit 原生属性，V5 回读当前 Client 克隆、实际容器和组件。按当前项目的视口、安全区、内容与尺寸变化采集独立运行轨迹并重验交互，单次结构化快照只证明记录一致，不能声称动态 resize 或视觉已通过。

系统 GUI、安全区、设备窗口和实际目标输入按 Roblox 实际情况验证；编辑器模拟、低保真原型或单个客户端结果不能代表其他设备或完整多人场景。项目自身不负责 Roblox 客户端原生启动屏、APK/IPA 或自建游戏服务器，除非任务还明确包含独立客户端或服务模块并选择其自身技术栈。

实施后按[测试等级](../../app-creator-workflow/references/verification.md)先推荐适用等级和实际命令，再自动运行授权范围内检查。交付分别报告文件/可编辑源、工程和用户视觉结论、已运行与未运行的 Studio/设备/线上环境，以及外部操作状态；没有目标预算或体验证据时不自行判定达标。
