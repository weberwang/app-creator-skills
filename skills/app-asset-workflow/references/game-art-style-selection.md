# 游戏美术与 UI 风格选型

游戏画面与 UI 共用一套全局美术方向，分别确定角色、道具和场景的画法，以及 HUD、菜单和控件的表现。镜头、画面构成、配色和渲染可按项目组合。

## 触发方式

- **阶段 4 推荐**。游戏视觉工作首次定义全局方向，或已确认方向发生实质变化时，按项目资料推荐一套组合。正式定方向前完成或核实复用[调研与参考](game-art-direction.md#调研与参考交付)。可独立推进的工程工作沿原流程执行。已有冻结方向仍适用时直接引用。
- **手动输出**。用户可直接说「列出游戏和 UI 风格」「按这个玩法推荐一套美术和 UI」或「原画指定像素，帮我配 UI」。列清单时按用户需要输出全表或对应部分。手动指定的方向按原意保留，只补齐未指定项。指定组合与已确认的玩法或平台条件冲突时说明具体影响，请用户决定取舍。

手动查看或推荐只输出文字。需要正式出稿时沿用[推荐稿与人工确认](game-art-direction.md#推荐稿与反馈)，3D 世界也可沿用[方向规格](../../app-workflow-control/references/world3d-scenes.md#方向人工确认和单次审查)。建议可写入现有视觉 brief，最终确认的规则写入现有风格规格。

## 游戏画面风格

| 维度 | 常用选择 | 选择依据 |
| --- | --- | --- |
| 造型语言 | 卡通造型 | 通过夸张比例、简化体块和清晰剪影突出角色、道具或动作。可用于 2D 和 3D。 |
| 绘画表现 | 平涂、手绘厚涂、水彩、水墨、纸艺拼贴、日式动漫 | 根据世界观、角色辨识度和目标体验选轮廓、笔触、纹理与细节密度。 |
| 画面构成 | 像素、矢量、体素、低多边形 | 像素以网格和色阶塑形，矢量擅长清晰的线面，体素适合块状空间，低多边形用概括体块表现空间。 |
| 渲染与材质 | 赛璐璐／卡通渲染、风格化 3D、半写实、拟真 | 决定光影、边缘和材质细节。赛璐璐式着色常用硬边阴影，拟真强调符合世界规则的尺度、材料和光照。 |
| 配色 | 单色、限色、冷暖对比、高饱和、低饱和 | 明确主体、背景、交互和危险各用什么颜色或明度。场景取色应给关键游戏反馈留出对比。 |
| 镜头 | 横版侧视、正俯视、斜俯视／等距、第一人称、第三人称 | 沿用已确认的镜头方案。评估画风在实际镜头下的遮挡、剪影和细节辨识度。 |

选择卡通方向时，分别写明造型和渲染。卡通造型可以搭配平涂、柔和 3D 光影或赛璐璐式硬边阴影。例如「圆润卡通造型 × 柔和 3D 光影 × 大色块 UI」。

## UI 风格

| 界面画法 | 常用表现 |
| --- | --- |
| 扁平／极简 | 清晰字阶、留白、中性色底、功能色和简化图标。 |
| 像素／复古 | 像素边框、限色图标、复古终端或 CRT 效果。 |
| 卡通／手绘 | 圆润或夸张轮廓、手绘图标、浅倒角和明确的按压反馈。 |
| 拟物／材质化 | 书页、手账、地图、牌桌、设备。用纸、木、金属等材质体现世界设定。 |
| 战术／科幻仪表 | 刻度、网格、数字和状态标记，按玩家操作顺序组织信息。 |
| 主题装饰 | 纹样、徽章、插画和装饰框，适合菜单、图鉴与结算。 |
| 漫画／海报 | 大字、斜切色块、剪影和夸张转场。 |
| 半透明／玻璃 | 用轻量底板托住文字和控件，保留场景可见性。 |

信息呈现按用途选用 **常驻 HUD、按需提示、世界内 UI、场景／地图／牌桌直接交互**。一套 UI 可同时使用多种方式，例如将血量常驻在边缘，把攻击预告标在棋盘上。区分场景部位色与 UI 功能色，关键状态可用形状、图标或文字辅助颜色。

## 如何推荐一套

1. 先读现有 GDD、技术方案与视觉 brief，提取核心循环、高频操作、世界观与目标情绪、镜头与目标视口、适用的制作约束以及已确认的风格。输入不足时，注明影响选型的假设，仍可给出一套方向建议。
2. 先按玩法确定玩家必须看清的目标、操作和状态，再根据世界观选画面表现，按镜头、平台和制作条件收敛。UI 的信息密度和出现位置由玩法决定。菜单和常驻 HUD 可有不同装饰强度，共享颜色、形状或材质中的具体规则。
3. 默认只给一套，理由落到当前玩法和题材。用户只问选型时直接交付文字。有明确分歧或要求比较时，再按[同条件对照](game-art-direction.md#推荐稿与反馈)补对照。

| 玩法参考 | 可比较的组合及关键取舍 |
| --- | --- |
| 经营种田 | 《星露谷物语》用暖色俯视像素和手账式菜单。背包按格组织，日期和时间常驻。 [官方图集](https://www.stardewvalley.net/media/) |
| 格子战术 | 《陷阵之志》用斜俯视像素和战术界面。威胁直接标在棋盘上，目标与回合信息放边缘。 [开发复盘](https://media.gdcvault.com/gdc2019/presentations/Into%20the%20Breach%20Postmortem%20Final.pdf) |
| 动作冒险 | 《空洞骑士》用手绘和简洁主题 HUD，以面具与容器表达战斗状态。 [官方演示](https://www.hollowknight.com/) |
| 空间解谜 | 《纪念碑谷》用等距感几何 3D，让建筑机关承担操作提示。 [设计案例](https://ustwo.com/work/monument-valley/) |
| 调查推理 | 《奥伯拉丁的回归》用单色 1-bit 3D 和拟物调查簿，线索与填写操作进入同一本书。 [官方演示](https://obradinn.com/) |
| 卡牌构筑 | 《小丑牌》用像素、CRT 与牌桌界面，分数和倍率独立突出。 [发行商案例](https://www.playstack.com/games/balatro) |

## 默认输出

- **游戏画面**：说明镜头、主要画法与一项关键配色或渲染规则。
- **UI**：说明 HUD 与菜单画法，以及关键目标、操作和状态各出现在哪里。
- **统一规则与理由**：指出两者共享的具体特征和对当前玩法、世界观的作用。有影响选型的假设时一并写明。

示例「森林拾荒与撤离」可用斜俯视纸艺拼贴，以低饱和墨绿表现地形。HUD 用扁平面板，只在边框沿用剪纸切角，背包沿用纸质菜单。物资和拾取按钮共用暖橙与同形图标，撤离剩余时间常驻，拾取提示靠近目标，让玩家在移动时分清路、物资和撤离状态。
