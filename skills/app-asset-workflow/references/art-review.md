# 去 AI 味审阅与返修

审阅目标是具体设计质量及系列一致性，没有可靠的“AI 味分数”可替代人的判断。以下条目是查漏依据，不要求所有项目采用同一种视觉风格。

## 当前设计稿的单次用户视角审查

当前视觉设计稿完成后、提交用户确认前，代理从目标用户角度审查一次，再依据本轮发现修改，最后将修改稿交给用户确认。仅审查本次明确交付的当前稿及其已知用途、状态和视口，不扩展到其他候选、页面、场景或全项目；首次三候选仍由用户比较选择，不借审查自动选定方向。

1. **审查一次**：结合已确认的目标用户与任务，观察当前稿能否让人理解所在页面／场景、找到主操作、辨认信息层级、可操作对象和关键状态；检查必要文字的可读性、误导性装饰及明显妨碍使用的布局。适用的[无文字意图判断](interface-intent.md#将去字检查放进现有审阅)和下表设计质量项并入这一轮，不另开审查轮次。不从静态图推断真实交互、运行性能或用户测试已经通过。
2. **按本轮问题修改**：只修本次发现且在既定需求和视觉方向内的问题，保留无关且有效的部分；没有具体问题时直接交付，不为凑修改重新生成。确需改变已确认方向或存在实质取舍时沿用既有决定流程，不擅自扩大目标。
3. **修改后交用户确认**：简述本轮问题、实际修改与未解决项，展示真实修改稿；不对修改稿自动再次开展用户视角审查，也不因修订版本、重新生成、换代理或续接任务而重置次数。用户后续指出问题时按其反馈修改；只有明确要求再审才开启新一轮，不自动循环优化至满意。

在现有设计记录或交接中注明当前稿已完成这一轮及问题处理情况，供续接时复用；不增加控制器状态、固定评分或必填审查表。修改后的必要文件、规格及既有工程检查照常进行，但不借技术核对重新开展设计评议。

这是设计稿的代理评议，不代替用户选图、V2 目标确认、V3 拆解／布局确认或 V4/V5 素材与正式组合验收，也不授权自动分析真实运行截图。对未修改的有效已确认目标直接沿用复用规则，不为本步骤重新审查。

| 缺陷 | 检查点 | 主要修复方向 |
| --- | --- | --- |
| 结构失真 | 肢体、机械连接、透视、对称与负空间是否合理 | 修复结构、轮廓或局部重绘，不加纹理遮掩 |
| 无目的细节 | 微饰件、随机符号、伪文字、无信息的高光 | 按目标显示尺寸删减，保留必要语义 |
| 材质混乱 | 金属/布料/纸张混成塑料，光照方向冲突 | 固定材质工艺与主光，分资产返修 |
| 系列漂移 | 同角色脸型、图标透视、线宽和色温不一 | 引用选中样本编辑，固定系列约束 |
| UI 模板感 | 无意义玻璃卡、随机渐变、假图表、填充头像、装饰标签 | 回到真实任务、数据与品牌签名；不是禁止一切渐变或玻璃 |
| 缺乏产品性格 | 全用默认控件或安全卡片堆叠，主次无变化 | 在合理预算内做有目的的构图/材质/插画特征 |
| 边缘污染 | 伪透明、色边、白边、烘焙阴影、裁断 | 重新导出 Alpha、局部遮罩或重生成，复查目标背景 |
| 组合不协调 | 密度、比例、空间、文字和主视觉争夺注意 | 定位为资源问题或布局/渲染问题，再由对应岗位修复 |
| 依赖文案才能理解任务 | 隐藏文字后，主次、可操作对象、动作或状态难以辨认 | 按[无文字意图可读性规范](interface-intent.md)调整形态、图形语义与位置关系，保留必要文案及无障碍标签 |

不要因装饰多就认定质量差，也不要因画面干净就认定完成。评价取决于主题、用户、可读性、观看情境和选定的视觉特征。

## 检查边界

代理可以核对制作规格、编号覆盖、文件/尺寸/Alpha/帧序和生产记录。当前设计稿按上节执行一次用户视角审查；真实运行截图及其他显示验收仍默认提供给用户人工检查，不自动读图并写出通过结论。用户明确要求自动视觉验证时才检查运行截图，并区分代理审阅与人工确认。

人工记录必须说明当前 candidateId、对象、结果、具体缺陷或接受理由及真实用户消息。未查看、未回答或只说“继续实现”不能据此补写全部美术 PASS。允许一次明确确认同时覆盖已展示的五项结果，不要求用户重复五次确认。

## 返修顺序

1. 目标/需求矛盾：只在确有决策冲突时拷问，更新受影响方向。
2. 拆解或规格漏项：补齐编号与生产归属，保留未受影响决定。
3. 源素材偏离：围绕具体问题编辑，不随机全量重生成。
4. 工程装配偏差：修复加载、材质、裁剪、布局、文字或输入，不重画已合格素材。
5. 同目标返修展示目标、修改前与修改后；素材／工程返修按原阶段复验受影响项，当前设计稿的单次审查修订后直接交用户确认，不因此再开用户视角审查。不反复审批文字修复方案。

V5 的真实运行场景还需关注普通操作、高频反馈、单次峰值和多事件叠加；按实际任务适用性记录，不为纯静态页面伪造游戏事件。技术指标通过不代表观看舒适与美术完成度通过。
