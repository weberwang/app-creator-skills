# Expo 显示、资源与性能

## 页面、布局与导航

完整页面是 `PAGE`，宿主内独立管理的弹窗、抽屉与瞬态显示层为 `DISPLAY_LAYER`。页面工作项明确当前路由、宿主和状态所有权；加载、空、失败、成功、返回、深链、恢复及异步取消按实际需要覆盖。导航容器、路由和全局宿主共享文件由明确的唯一写者维护。

React Native 原生页面以逻辑像素、实际父子组件、Flexbox、滚动容器和安全区为布局依据，不能套用浏览器 DOM/CSS 像素、游戏相机或 Flutter Widget 证据。按[公共相对布局](../../app-ui-layout/references/relative-layout.md)明确父级、参照和实际层序；浮层本体例外不扩展到内部普通控件。验证代表性宽高及实际支持方向、设备安全区、键盘开合、长文案、系统文字缩放、滚动/焦点、点击区域和无障碍标签。Web 目标若选择启用，应另测其浏览器布局、键盘和可访问性，不将 Web 结果写成原生结果。

文本配置与适配读取[文本布局](text-layout.md)，对实际 Text/TextInput 的字号、换行和系统文字缩放分别验证，不能只检查容器几何。

## 前台加载与弹窗

沿用[统一加载服务及显示层](../../app-domain-toolkit/references/reference-domain-display-ownership.md#场景与弹出层统一加载)：页面切换和应用自有弹窗使用同一服务及全局加载职责，页面切换用不透明过渡，弹窗需要等待时用半透明蒙层；缓存命中且可同步显示时不闪现蒙层。请求身份、令牌、并发优先级、失效结果、输入隔离与焦点恢复均按公共合同实现。

React Native 的原生 `Modal` 可能位于不同原生窗口/层级。设计全局加载宿主时先确定实际窗口的覆盖、返回键、屏幕阅读器焦点与输入处理；必要时将**同一服务控制的显示职责**承接到当前最顶层宿主，不能因为组件层级问题出现两个独立加载服务或让加载蒙层被 Modal 遮住。系统及 SDK 原生窗口仅调用其公开能力，不伪造其生命周期。

弹窗仅在首次触发时按需加载；缓存可复用模块、组件定义、图片及依赖资源，不缓存已挂载的弹窗实例或过期业务状态。关闭时卸载弹窗并清理所属请求、订阅、计时器和动画；重开创建新实例并读取当前数据。页面切换释放旧宿主私有内容与任务，后台预取不显示全局蒙层；资源不能取消时也必须阻止迟到结果改写当前宿主。

加载服务/基础视图、正式视觉设计与素材、页面和弹窗接入、并发/取消及输入验证分别按公共工作流安排任务。服务代码通过不能代替正式加载显示或用户视觉确认。

## 资源与性能

真实图片、字体、图标和媒体按项目实际的 Expo/React Native 资源链登记及导入，记录来源、许可、适用平台、尺寸与用途；保留可编辑制作源和运行资源各自位置。首帧必需的少量本地资源先于应用可用准备，非必需资源和数据按需加载，离线和失败有可恢复路径；不为等待全部网络资源延长系统启动屏。动态文案、按钮与交互必须保留真实可访问组件，不能以整页截图代替。

复用项目实际资源缓存；记录下载、解码、组件卸载与缓存释放的所有者，验证资源引用和平台打包结果。普通 App 不默认生成或更新图集；用户选择性能检查/优化或确有实测瓶颈时再按[性能规范](../../app-domain-toolkit/references/performance-optimization.md)处理，并单独确认图集选择。

性能工作先固定候选、平台、设备或模拟环境和测试场景，采集可比基线；分别关注启动、JS 线程、UI 线程、长列表、无效渲染、图片内存、网络与包体。针对瓶颈选项目版本实际支持的工具复测，记录受影响功能回归及副作用；development、模拟器或 Web 结果不能冒充原生 release/目标设备结果，不在普通任务里自动启动真机。
