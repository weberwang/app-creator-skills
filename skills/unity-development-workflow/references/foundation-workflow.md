# S00 基础工作流

## 何时读取

全局技术基线与项目语言范围确认后、正式场景实现前，或基础能力需要变更时读取。S00 完成基础工程与国际化配置的结构回读；行为、编译和构建证据由后续适用工作项取得，正式字体外观与布局在对应视觉阶段确认和验收。

## 输入

- 已通过的项目发现、用户确认且状态为 `APPROVED` 的 `project-profile` 与 `decomposition-plan`、module-manifest、场景 DAG 和当前有效的 Visual Bible。视觉稿未冻结不阻塞已确认技术与语言范围内的国际化基础实现，不提前宣称视觉验收通过。
- 已确认的项目语言清单、固定 JSON 文案配置路径及本批真实文案，TDD 中的唯一初始化入口、语言优先级和统一绑定接口；具体规则按[国际化初始化时机与阶段职责](text-and-localization.md#初始化时机与阶段职责)。
- 全部场景 manifest 草案与共同能力清单。
- 已按 `unity:unity-cli` 当前规则发现并唯一绑定的 Unity Editor 目标。

## 执行步骤

目标包含 Android 或 iOS/iPadOS 时，在基础工程内按[系统启动屏规范](../../app-domain-toolkit/references/system-launch-screen.md#任务安排与完成条件)落实平台配置与随包资源；首帧衔接、运行和人工显示检查由后续适用工作项完成。Unity 内建 Splash 与系统启动屏、首场景之间的显示关系按锁定版本和许可要求核对；Editor/Game View 不能证明原生启动链路通过。

1. 深度校验当前拆分决策的对象 ID、用户确认、模块/场景边界、恢复出口和活动指针；确认仍处于批准状态且用户确认覆盖当前实际范围。版本号、`sourceRevision`、`projectStateVersion` 用于识别来源与记录变更，不单独构成失效或验收阻断条件；只有批准范围实质变化、确认已撤回/被拒绝或对象身份不明时才停止 S00。
2. 创建 S00 任务并冻结共享骨架范围。
3. 建立最小目录、程序集、Composition Root、启动入口、场景加载、输入、时间/随机抽象、配置、存档版本边界、uGUI/UniText 基础、固定 JSON 文案加载与统一语言绑定、公共安全区适配、日志与测试骨架。屏幕 UI 统一复用 Toolkit 的 `SafeAreaRectTransform` 或 `SafeAreaVisualElement`；全屏背景和遮罩留在安全区节点之外。游戏显示默认全屏；尺寸、方向或安全区变化后重算显示与输入映射。目标包含 Android 时，纳入冷启动无系统标题栏、沉浸式全屏，以及应用恢复前台/窗口焦点后重新建立沉浸显示的要求。
4. 国际化作为项目级启动基础能力在 S00 完成实现及静态配置回读，不以两个场景共同消费为前置；单场景同样适用。其运行和用户可见结果按[后续国际化验证](#国际化基础能力验收)处理。
5. 项目采用的 SDK 必须通过[TDD 中唯一映射的统一初始化入口](./sdk-initialization.md)独立投递初始化任务；不等待 SDK 批次完成再显示首帧或启动首个场景，也不绕过 SDK 自身真实官方前置。
6. 按[产物存放规则](./artifact-storage.md)固定源文件、正式资源、临时/候选文件、人工审阅/验证、确认成果和机器 `evidenceRoot` 的路径；冻结引用不得为目录整理批量迁移。
7. 可并行准备不写 Unity 的契约、测试清单和资源说明。
8. 串行执行 asmdef、场景、资源和共享状态的 Unity 正式写入。
9. 回读已保存的场景、显示树、接口、配置和实际引用，执行适用 Schema 与静态检查；记录未执行的玩法、编译和打包验证。
10. 审查 S00 实际结构和引用，完成后按模块计划进入阶段 5；运行、编译和构建安排到后续实际需要的工作项。

## 子代理角色与并行边界

- 契约、测试设计和资源盘点可由子代理并行准备。
- Foundation 开发代理串行写入 Unity；QA 代理和架构审查代理独立验证。
- 后续场景代理可以只读准备需求，但不得提前写正式共享状态。

## 所需锁与 Unity 权限

- S00 是全局骨架代码的正式实现时点，写入持有 Foundation、Shared 和启动场景路径的独占锁。
- 任何写调用前按 `unity:unity-cli` 当前规则复核唯一目标，并显式绑定项目绝对路径。
- 后续执行构建时持有构建输出目录独占锁。

## 机器可读输出

以 `schemas/s00-report.schema.json` 和 `templates/s00-report.yaml` 输出 `s00-report.yaml`。国际化实现记入 `scope`、实际 `changedPaths` 和 `qualityReports`，后者引用本次配置、接口、源文件与结构回读证据。`sharedCapabilities` 只列有至少两个场景需求的可复用业务能力，不为国际化伪造第二个场景。S00 进入 `PASS` 前核对当前对象身份、批准范围、实际变更及已保存 Unity 事实；编译、构建与运行绑定的未执行项单独记录。SHA/hash 不作为验收硬门。

## 通过条件

- 固定模板对应的入口、目录、公共宿主及显示层挂载按实际源码与已保存场景回读，国际化初始化、配置和绑定接口存在且引用正确。
- 游戏方向、安全区、音频生命周期及适用 Android/iOS 启动配置已按本批方案落实；运行行为、首帧显示和目标设备结论留待后续适用工作项，未执行时标为 `NOT_RUN`。
- 拆分决策仍为当前批准版本，模块清单与场景草案未越过用户确认边界。
- 列入 `sharedCapabilities` 的可复用业务能力均有至少两个场景的需求证据；国际化等已明确的项目级启动基础能力按自身验收记录，不伪造消费者。独立审查已批准。

## 国际化基础能力验收

以下运行与编辑器行为检查由阶段 5 或后续适用工作项执行。S00 只完成配置、代码和已保存对象的结构回读；其中的插件编译、Domain Reload、Play Mode 和运行结果均不构成阶段 4 推进条件。

1. **实际插件可用**：记录 UniText 版本、包来源、依赖、程序集与组件/字体/材质检查，编译及 Domain Reload 无相关错误，并实际调用本工作项所需绑定能力。安装异常须先由用户选择修复或 TMP 回退；选择 TMP 时验证其可用性，后续仍使用同一 JSON 源，未决定时相关项保持未完成。
2. **正式 JSON 可加载**：从登记的项目正式路径和加载入口读取固定模板配置，校验语言范围、默认语言、键唯一性、逐语言翻译及命名参数，建立实际查找索引。记录真实文件、加载方式和校验结果，不能用内存样例或硬编码翻译替代。
3. **启动状态可验证**：唯一入口落实已确认的启动语言优先级；实际记录所用语言来源和最终语言。正式文案就绪前不展示依赖文本，损坏/缺失配置不会被当作空表成功；重复初始化或重新进入不会创建第二套服务与订阅。
4. **统一绑定可运行**：最小运行宿主中代表性消费者以文案键和真实参数驱动已选文本表现（默认 UniText；用户明确选择回退时为 TMP；无法原生还原效果时为图片），首次显示和参数变化均来自同一 JSON。多语言项目验证切换后所有已挂载的代表性消费者更新；单语项目验证默认语言、重复选择及参数刷新，不为测试追加语言。按实际存在的动态创建、禁用/重启用和池化消费验证补刷与取消订阅，不新增无业务用途的显示对象凑数。
5. **失败和范围不被掩盖**：对缺键、缺参数、缺翻译及配置错误执行可重复的定向检查，保留可定位失败和受控结果；不通过组件语言分支、硬编码多语或默认语言掩盖缺失。检查覆盖本批所有文案消费入口，不限定 HUD 或名称带“国际化”的组件；完整项目覆盖留到后续功能及集成阶段。
6. **编辑器预览可用**：按[同源编辑器预览](text-and-localization.md#编辑器预览)在非 Play Mode 的正式 Scene、Prefab 及实际采用的模板/世界文字中，以项目正式 JSON 和代表性绑定验证所选语言、样例参数/状态、配置重新导入后的自动刷新；已采用的图片文字同步验证资源切换。保存并重新打开后文案键和样式引用完整，预览翻译、语言与样例不污染正式源或运行时偏好；退出预览及重载无残留订阅、临时覆盖或实例。缺配置/资源有诊断，不以仅运行可见代替编辑预览，也不以预览代替第 4 项运行验证。
7. **证据可追溯**：现有 `qualityReports` 引用真实命令/API、目标工程、配置与场景/对象、编辑预览操作、执行结果及未覆盖范围；独立审查核对上述链路。配置校验或容器几何通过不能替代运行绑定；截图显示仍由用户检查，未执行的目标平台、视觉或设备检查单独记录，不自动启动真机。

上述条件是后续国际化运行验收要求，现有报告 Schema 仅检查材料结构，不会自动执行插件安装、JSON 加载、绑定或行为验证。缺少所需运行环境或证据时如实保持对应运行项未完成，不把模板存在当作运行验收通过。

后续代表性绑定验证只覆盖实际启动与文案服务链路。具体目标仍按[四维标准与三种结论](visual-decomposition-routes.md#完整还原的判断标准)核实；未核实的目标保持待验证，不因 S00 已通过就自动归为原生。

## 失败与恢复出口

- 骨架失败时保持 S00，不得启动正式场景写入。
- 非共同能力下沉到所属场景后重跑门禁。
- 共享接口变化时更新 DAG 并评估所有场景影响；后续按实际工作项执行必要编译验证。
