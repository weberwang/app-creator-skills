# 单页高保真效果图提示词模板

## 精简生图提示词（唯一发送给生图模型的内容）

删除未填写字段，并继续压缩到不损失正确性的最短版本。通常只需几句短句；不要把上述工作表改写成长文。

低保真只提供页面范围、必需内容、信息优先级、任务、状态、导航、交互结果、可访问性语义和内容归属。不得把低保真的坐标、卡片/容器、留白、组件轮廓、图像比例与裁切、图文方向或装饰位置写成生图约束；允许模型在冻结方向内重新组织视觉表达。

```text
设计一张面向[目标用户]的[产品名称][页面名称]高保真移动端页面，核心任务是[首要目标]，当前处于[单一页面状态]。
页面以[关键区域和信息层级]为主，必须出现[关键内容、真实文案或数据]。
遵循[已冻结视觉方向及可复述签名]，突出[少量具体视觉特征]；在此方向内自行决定次要构图、光影、装饰节奏和微观细节。
必须保持[范围、主 CTA、信任/安全、可访问性、关键相对关系和停靠/系统避让行为等真正不可协商项]；不要把绝对坐标、卡片像素尺寸或单一视口比例写成约束。
输出正视角、无设备外框的完整页面，780×1688 px。仅避免[最可能且影响重大的失败模式]。
```

发送前删除重复要求、空泛形容词、来源说明、设计理由、评分标准、组件清单和无关负面词；若两项要求冲突，优先保留已确认范围与内容、冻结视觉方向、页面状态与可用性、输出规格，并删除较低优先级描述。
