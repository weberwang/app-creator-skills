# 页面效果图独立审阅提示

向用户展示页面效果图及检查要点，由用户检查显示效果并作出选择。未经用户明确授权不得自动分析截图或效果图；技术审阅可核对已验证页面语义、适用的布局规格、全局视觉方向和预算，只有选择 Code Sketch 路线时才引用其审阅。以目标平台的交互原则检查可验证的结构事实，不要求复制特定平台的视觉风格。

记录用户对视觉层级与品牌表达的实际反馈，以及技术证据中的任务/状态/导航语义、无障碍、系统区域、Flutter 可实现性和资产影响。范围、状态、导航、滚动 owner、断点、无障碍或 ownership 变化时更新受影响的功能与语义并重验；仅已使用草图路线时更新草图及其审阅。
