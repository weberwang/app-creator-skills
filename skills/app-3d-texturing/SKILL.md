# 三维材质与贴图生产

将材质意图转成可正确显示、可维护且符合目标设备预算的材质与贴图交付，避免纹理接入错误被误判成模型问题。

执行前阅读[公共执行协议](../app-creator-workflow/references/professional-execution.md)。以下共用步骤不能跳过所选原生适配规定的操作顺序、资源格式与平台边界；必要的用户确认按协议执行。

3D 世界白模、空间方案和方向按[正式生产交接](../app-domain-toolkit/references/game-design-exploration.md#production-handoff)获人工确认、模型材质槽与 UV 已交接后，在当前工作项的 V4 按需安排材质贴图。独立素材或不改变世界空间的局部修改按原范围处理，不要求重建整体白模。

## 输入

- 可追溯的当前模型版本、UV与材质分区；渲染风格和色板；贴图通道、最大尺寸、压缩及纹理内存预算。

## 共用操作步骤

1. 审查模型材质槽、UV重叠/拉伸、像素密度、接缝和镜像限制；先确定唯一材质真源及实例/共享资源策略。
2. 将表面拆为基础色、法线、粗糙度/金属度、遮罩或栈所需通道，说明每通道色彩空间、数值范围和缺省值。
3. 固定全局色板、材质响应、磨损/细节尺度和光照参考；在代表性光照与背景下制作样本，避免只依据贴图平面预览。
4. 为每张贴图记录分辨率、位深、格式、Alpha、压缩、用途与可复用对象；按可见贡献削减分辨率和重复图集。
5. 在目标渲染路径回读材质槽和通道，检查接缝、法线方向、色彩空间、伽马、压缩伪影及移动端采样成本。
6. 交付可回源的材质配置与纹理、通道表、预算和目标光照下的人工检查事项。

## 按目标画面强化纹理

以目标引擎的实际观看距离、画面占比和代表性光照为依据。先做一处能代表主要材质的表面，确认大块材质分区在常用距离下清楚可辨，再添加接缝、使用痕迹和近看才有用的微细节。风格化资产的色块、笔触和细节密度沿用已确认的美术基线。

- **用通道分工拉开材质差异。** 基础色表达材料本色、涂层、图案与有依据的色差。粗糙度或光滑度控制反射的锐利程度，优先用它区分抛光、涂层和消光表面。使用金属度工作流时，按实际露出的基材区分金属与涂层。动态受光资产的固定高光和投影留给场景照明处理。
- **结合结构描绘表面。** 目标着色器支持时，用法线表现浅槽、压纹和颗粒，用遮挡通道表现适度的凹处遮蔽。按接触、摩擦或积尘位置布置变化。例如涂漆金属把掉漆限制在实际易磨部位，露底处的颜色、金属度与粗糙度一起反映裸露金属。需要明显改变轮廓或遮挡的细节交回建模。
- **把细节预算用在可见面。** 优先保证主视面、交互部位及近景的有效纹素密度，检查 UV 拉伸和接缝。根据实际导入配置检查近景清晰度、远景 Mip 衰减及压缩后的伪影。细纹若在正常视距闪烁，优先调整纹理尺度或反差，确认确有像素不足再提高分辨率。
- **用同条件对照确认改动。** 在实际模型上用同一机位、光照和曝光提供修改前后对照，按需加近景和掠射光。由用户人工检查材质分区、粗糙度层次、凹凸方向、接缝和移动时的稳定性。根据问题定向调整材质、UV 或照明，已交付的贴图按实际导入配置回读。

## 关键边界

- 原生适配以本技能清单为准；当前栈没有映射时使用通用流程与该栈实际规范，不猜测导入/着色器能力。
- AI生成的贴图不能自动保证无接缝或PBR物理正确，需按实际网格和灯光检查。

## 交付

- 按[三项最小约定](../app-creator-workflow/references/output-files.md#每项任务的最小约定)交付当前范围的结果、涉及文件的实际路径和验证结论；沿用已有材质／通道规范及记录，保留适用的 UV 问题、贴图用途与格式、通道色彩空间、尺寸预算、目标渲染回读和人工视觉检查事实。纯方案或局部调整可在对话或现有工件交付，不强制新建整套材料；未运行或待确认项如实标明。
