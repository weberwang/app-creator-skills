# 三维材质与贴图生产

将材质意图转成可正确显示、可维护且符合目标设备预算的材质与贴图交付，避免纹理接入错误被误判成模型问题。

执行前阅读[公共执行协议](../app-creator-workflow/references/professional-execution.md)。以下共用步骤不能跳过所选原生适配规定的操作顺序、资源格式与平台边界；必要的用户确认按协议执行。

## 输入

- 已确认的模型、UV与材质分区；渲染风格和色板；贴图通道、最大尺寸、压缩及纹理内存预算。

## 共用操作步骤

1. 审查模型材质槽、UV重叠/拉伸、像素密度、接缝和镜像限制；先确定唯一材质真源及实例/共享资源策略。
2. 将表面拆为基础色、法线、粗糙度/金属度、遮罩或栈所需通道，说明每通道色彩空间、数值范围和缺省值。
3. 固定全局色板、材质响应、磨损/细节尺度和光照参考；在代表性光照与背景下制作样本，避免只依据贴图平面预览。
4. 为每张贴图记录分辨率、位深、格式、Alpha、压缩、用途与可复用对象；按可见贡献削减分辨率和重复图集。
5. 在目标渲染路径回读材质槽和通道，检查接缝、法线方向、色彩空间、伽马、压缩伪影及移动端采样成本。
6. 交付可回源的材质配置与纹理、通道表、预算和目标光照下的人工检查事项。

## 关键边界

- 当前原生专门适配来自Unity；其他栈没有映射时不要猜测导入/着色器规范。
- AI生成的贴图不能自动保证无接缝或PBR物理正确，需按实际网格和灯光检查。

## 交付

- 材质/通道规范、UV问题清单、贴图文件、尺寸预算、目标渲染回读和视觉审查记录。
