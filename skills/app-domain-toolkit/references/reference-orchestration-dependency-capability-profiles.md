# 依赖与能力检查

执行公共规则时，同时读取当前技术栈参考中的原生补充和“本栈配套资料”。各段仅适用于标注的技术栈；结构化证据不代替用户对显示效果的人工验收。

## 能力档

> 适用技术栈：cocos、phaser。

每个新增依赖在 TDD 记录能力档、启用原因、拒绝的 SDK/现有依赖/轻量方案、维护成本、运行时性能和平台风险、验证命令及所有者。一个项目可组合多个档位；能力未采用时不创建 `N/A` 条目。

## API 与服务边界
