# 正式场景布局校准与参考还原

执行公共规则时，同时读取当前技术栈参考中的原生补充和“本栈配套资料”。各段仅适用于标注的技术栈；结构化证据不代替用户对显示效果的人工验收。

示例中的相对脚本和文件路径按当前技术栈的原生资料与项目约定解析；运行前核对已安装的专业资源位置。

各技术栈统一使用 V0–V5；V1 验证功能且白盒可选，V2–V5 依次完成视觉目标、拆解布局、资源导入和运行验收。

## 正式场景布局校准与参考还原

> 适用技术栈：cocos、phaser、threejs。

V3 决定目标关系和初始布局，V4 提供匹配节点的真实资源。V5 在真实 viewport、字体、动态数据和所需状态下组合它们。对照参考时尽量保持相同 scene/state、视口、语言、运行时有效 DPR、随机种子和动画时间点；记录实际运行条件和对应候选。

## 校准步骤

> 适用技术栈：cocos、phaser、threejs。

1. 在正式 Scene 中运行代表性状态，直接观察完整可读画面及交互；按需在同一逻辑坐标空间对照 V3 关键节点和冻结目标。

> 适用技术栈：cocos、phaser、threejs。

2. 定位偏差来源：目标 bounds、父级、职责、锚点、层级或响应式事实错误时更新 V3；资源外观、尺寸、透明边缘、切片或内容状态缺失时修复 V4；实现坐标、尺寸、资源 origin、文本排版、实际状态绑定和 resize 行为错误时在 V5 修复。

> 适用技术栈：cocos、phaser、threejs。

4. 按项目 `orientationPolicy.allowed` 覆盖代表性窄/宽视口、安全区、DPR、连续 resize 和适用方向。弹窗按自身 `DISPLAY_LAYER` 合同检查打开、交互、关闭及宿主恢复。

> 适用技术栈：cocos、phaser、threejs。

截图、叠图和差异材料供用户人工检查。代理不自动分析截图，不以视觉比对推导用户已确认，也不把测量或机器 PASS 当作美术通过。

## 布局读数与边界

> 适用技术栈：cocos、phaser、threejs。

测量值统一使用合同声明的逻辑空间，按节点记录目标与运行时的 x/y/width/height、关键边距、组间关系和容差。CSS 缩放或 Canvas backing 像素不能直接当作逻辑位置偏移。父节点移动对后代的影响由正式布局关系产生，不能在父、子坐标上重复累计同一偏移。

> 适用技术栈：cocos、phaser、threejs。

布局矩形和资源可见边界分别检查。纹理透明留白、`contain`/`cover` 裁切、字形墨迹、字体 fallback、baseline、光效外缘可能使画面内容超出或小于矩形；机器 bounds 通过不能证明轮廓或文字视觉对齐，需由用户检查实际画面。

> 适用技术栈：cocos、phaser、threejs。

| 偏差来源 | 处理方式 |
| --- | --- |
| V3 目标 bounds、父级、对齐语义、层序或空白用途错误 | 修正受影响 V3 事实并重新确认布局，不在 V5 隐藏结构错误 |
| 位图透明边距、主体比例、纹理适配或外观不符 | 回 V4 修复素材或已声明呈现规则，保留合法辉光、阴影与主体边界 |
| 字体、字号、换行、真实字形或 baseline 不符 | 在 V5 修正文字呈现或字体资源，并检查相邻节点与留白 |
| 实现位置、尺寸或响应式关系偏离冻结合同 | 在 V5 更新正式布局配置，重验受影响状态和视口 |
| 基准视口正确、设备尺寸出现间距变化 | 检查设计变换、父级参照、安全区、方向和幂等重排入口 |

> 适用技术栈：cocos、phaser、threejs。

不得把“可用、没有越界”当作已经忠实还原，也不得把所有空白都填满。焦点留白、反馈空间、场景纵深和安全区各有职责，按冻结目标与玩法意图保留。

> 适用技术栈：phaser、threejs。

V3 图片目标框按完整未裁切源纹理定义，主体安全边距与合法光影空间属于内部构图。若冻结图测量只取可见主体，应在 V4 生产前统一画布与主体比例；不使用 V5 移动对象去补偿透明边距、纹理比例或错误尺寸。默认文字实测超框应修正字体、内容、尺寸或容器；显式 `overflow="visible"` 仍需检查相邻节点与留白。

## 关键几何验收

> 适用技术栈：cocos、phaser、threejs。

`usability` 是默认值，不要求整屏像素差或全矩阵。项目在 `critical_alignments[].tolerance` 中声明关键矩形几何容差时，机器必须校验实际 x/y/width/height 与目标的差值，即使仍使用 usability；不能靠 `test_status=passed` 或手写 delta=0 放行超差。单位使用同一测量空间的 `px`、`logical-px`、`css-px` 或 `css-logical-px`，由项目决定，不把编辑器网格当作验收阈值。

> 适用技术栈：cocos、phaser、threejs。

只有用户或合同明确要求整屏精确还原时才启用 `exact` 的严格材料与矩阵。机器几何通过与用户确认显示效果分别记录；人工确认不能豁免已声明却未满足的关键几何要求。

> 适用技术栈：phaser、threejs。

V3 在 `critical_alignments` 与布局不变量中声明关键对齐线、主区域边距、节点矩形和组间关系，并明确适用视口、scene/state 与语言。V5 对照这些事实并采集同条件的真实 bounds；不同视口按已声明的响应式关系验证，不能把基准绝对坐标套到所有设备。
