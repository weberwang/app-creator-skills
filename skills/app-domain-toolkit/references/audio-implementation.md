# 音频基础服务与验证

本规范是列入迁移清单的技术栈共用的完整规则。每段标明适用栈；执行时同时读取本栈技能的原生约束与“本栈配套资料”，资料路径和具体工具由栈入口维护。公共状态与授权仍由 app-workflow-control 管理。

## 完整流程

### 专业执行与交付（cocos、phaser、threejs）

读取全局 Work Item、项目规格、资源登记和测试计划。按 F0 范围与流程、F1 规格一致性、F2 音频质量、F3 工程验证和 F4 集成/发布决策提交证据；音频方向确认不等于 A4-A6 操作批准。

### 专业执行与交付（cocos、phaser、threejs）

汁水感任务可按需参考“动态反馈设计指南”（见本栈配套资料）中的事件语义与声音层次；音频仍独占音频实例生命周期、后台暂停与恢复规则，不由反馈编排另行管理播放实例。

### 后台暂停与恢复约束（cocos、phaser、threejs）

- 基础实施包和 TDD 记录音频实例所有权、播放位置、暂停原因、生命周期入口与清理策略。验证覆盖播放中切后台后无声、返回后原位置续播、重复切换不叠播、手动暂停不误恢复、后台停止/销毁不复活、后台新请求不补播及恢复受限后的重试。源码检查或构建不能替代实际播放证据；没有运行证据时列为未验证，真机验收不得自动执行。
