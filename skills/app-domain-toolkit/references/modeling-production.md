# 正式三维模型生产

本规范统一几何建模及交接要求。选择 Blender 时按 [Blender 场景生产接入](blender-scene-production.md)读取 `blender-director` 及相关上游技能，作为制作的主要实现；实际导出格式、目标工程和导入验证方式由所选技术栈确定。

游戏场景先按[整体空间与制作单元](game-design-exploration.md#scene-production-units)明确制作范围。正式引擎维护整体可玩空间，制作工具按本栈所选原生路线确定。建模简报引用已有空间和制作单元依据，保留原有通路、占地和独立替换接口。

## 生产流程

### 冻结模型简报

冻结模型简报：记录已批准的视觉基线（如 Unity Visual Bible）、用途、目标轮廓与观看距离、单位和轴向、Pivot、玩法交互体积、拓扑与面数预算、材质槽、适用 LOD 和碰撞代理、导出格式、许可、来源、输入输出路径及目标工程。缺少会改变模型形状、预算或导入结果的事实时，先标出假设并停下受影响的生产。

V3 在原规格中引用已有设计稿或说明无需补稿的理由。固定镜头下结构明确的模型可沿用主视角和尺寸标注；可绕看的角色、载具或近景道具按遮挡和结构歧义补正、侧、背或俯视图；接缝、转轴及带厚度的开口优先用局部剖面或尺寸标注表达。各视图统一比例、姿态和部件位置，图稿冲突时先在原规格中明确尺寸和接口。V3 设计稿用于指导制作；V4 检查图从实际模型截取，供用户人工核对。

### 先试接代表样本

选择能暴露本批主要风险的制作单元，例如拼接模块的接缝和通行，或近景道具的轮廓和结构。依照[正式生产交接](game-design-exploration.md#production-handoff)先完成样本，在目标引擎回读并试接，完成现有样本审阅后记录通过的结构做法、材质分区与导出设置，再启动依赖样本的批量单元。

### 检查 Blender 工作区

仅在所选原生路线需要 Blender 时执行本段。制作前检查可复用的 Blender 实例、活动文件、对象集合、工具和未保存状态；先核对当前 MCP 工具及参数，不把脚本可运行误认为所需能力都可用。只有确认无可复用实例后才启动；不得重置场景或覆盖无关对象。保存带版本的 `.blend` 源、工具版本、可复现配方、关键参数和派生关系；按目标格式实际需要，在独立副本上应用修改器、三角化或轴向调整，重新打开并读取真实导出物，核对对象、网格、UV、变换和预算。Studio 原生路线使用和回读实际的 Studio 模型。

### 完成模型结构

按冻结规格制作形体和结构：根据目标在硬表面结构建模或有机雕刻间选择，落实需要的厚度、连接、转折、倒角和曲面；需要高低模时完成高模与重拓扑，直接低模路线仍须有合理边流和真实结构。需要绑定的角色同时执行本栈的重拓扑前置和角色交接。Blockout 只用于比例、轮廓或玩法空间检查，不能作为正式可见模型交付；若目标本来就是简单几何，则完成其必需结构与技术检查即可，不为增加复杂度堆叠细节。基础几何体只能作为起始网格、中间检查或碰撞代理。

先分析主次形体、连接、厚度、开口、材质分区、可动件和玩法体积；用目标机位和尺寸参照核对比例、轮廓与交互体积。硬表面或有机模型按需要选择挤出、放样、布尔整理、倒角、曲面塑造、雕刻或多边形建模，关键结构须由实际网格表达。记录模型 brief、结构方案和中间候选身份；显示证据交用户人工检查。

正式可见模型和 V4 代表样本禁止使用程序切面和程序色块。开口、截面、厚度和连接由可编辑的正式几何表达。颜色分区使用有明确用途的正式材质槽、原生材质或贴图；低多边形或平涂风格可以使用符合方向的正式纯色材质。临时切片、调试材质和标识色仅用于中间检查，须在正式导出和接入前清除。

### 核对表面与性能预算

完成拓扑清理、法线与切线策略、UV 展开与检查，冻结实际 UV 位置及报告、材质槽和烘焙交接信息；按预算准备适用的 LOD 与碰撞代理。不以贴图、光照、高面数、增加零件、细分或光滑着色掩盖未完成的几何；不要求所有模型都雕刻高模或使用全四边面，制作方法由形体、变形和烘焙需求决定。

- 清理重复点、退化面、内部废面、意外重叠壳、反面和非有限坐标；开放或非流形边界按设计说明，变形区域按需求布线。记录顶点与面数、拓扑例外、硬边/平滑、法线与切线及导出三角化策略。
- 规划 UV 接缝、展开和排布，检查拉伸、越界、重叠、Texel Density 与 Padding；区分允许重叠的纹理 UV 和需要唯一性的烘焙／光照 UV。报告实际通道与岛位置，按需交付匹配的高低模、Cage／射线方案、命名和法线／三角化策略。
- 按预算制作适用 LOD 网格与碰撞代理，逐级记录面数、顶点数、轮廓、材质槽、阈值和碰撞类型及数量；简化保留关键孔洞、薄件、交互边界及所需变形。不适用的高模、额外 UV、LOD 与碰撞按实际说明。
- 保存版本化可编辑源和必要依赖，在派生副本按需应用修改器、变换、法线和三角化；只导出约定对象与依赖，排除无关参考、灯光、相机、灰模及高模源。记录对象、参数和输出位置，重新读取导出物核对尺度、朝向、Pivot、网格、UV、材质槽和意外依赖。正式引擎导入及运行回读由本栈资产接入负责人执行。
