# 正式三维模型生产

本规范统一几何建模的共同步骤。按需同时读取所选技术栈专业技能，决定实际支持的导出格式与导入验证方式；本规范不决定专属插件、资源身份或运行时管线。

## 生产流程

### 冻结模型简报

冻结模型简报：记录已批准的视觉基线（如 Unity Visual Bible）、用途、目标轮廓与观看距离、单位和轴向、Pivot、玩法交互体积、拓扑与面数预算、材质槽、适用 LOD 和碰撞代理、导出格式、许可、来源、输入输出路径及目标工程。缺少会改变模型形状、预算或导入结果的事实时，先标出假设并停下受影响的生产。

### 检查 Blender 工作区

制作前检查可复用的 Blender 实例、活动文件、对象集合、工具和未保存状态；先核对当前 MCP 工具及参数，不把脚本可运行误认为所需能力都可用。只有确认无可复用实例后才启动；不得重置场景或覆盖无关对象。保存带版本的 `.blend` 源、工具版本、可复现配方、关键参数和派生关系；按目标格式实际需要，在独立副本上应用修改器、三角化或轴向调整，重新打开并读取真实导出物，核对对象、网格、UV、变换和预算。源文件与导出成功提示都不能替代回读。

### 完成模型结构

按冻结规格制作形体和结构：根据目标在硬表面结构建模或有机雕刻间选择，落实需要的厚度、连接、转折、倒角和曲面；需要高低模时完成高模与重拓扑，直接低模路线仍须有合理边流和真实结构。Blockout 只用于比例、轮廓或玩法空间检查，不能作为正式可见模型交付；若目标本来就是简单几何，则完成其必需结构与技术检查即可，不为增加复杂度堆叠细节。基础几何体只能作为起始网格、中间检查或碰撞代理。

### 核对表面与性能预算

完成拓扑清理、法线与切线策略、UV 展开与检查，冻结实际 UV 位置及报告、材质槽和烘焙交接信息；按预算准备适用的 LOD 与碰撞代理。不以贴图、光照、高面数、增加零件、细分或光滑着色掩盖未完成的几何；不要求所有模型都雕刻高模或使用全四边面，制作方法由形体、变形和烘焙需求决定。
