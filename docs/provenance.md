# 来源与逐项去向

本轮以五个本地源仓库的 Git NUL 文件清单为审计输入，按能力合并公共入口。原专业名称仅作为来源身份和原生资源包名称保留，不再提供同名 SKILL.md；完整原生规范改为 ADAPTER.md。共同正文与算法维护一份真源，脚本、模板、校验器、工具包和配套测试逐项承接。源仓库只读，未跟踪示例、缓存和输出不属于本次跟踪基线。

## 公共能力去向

- 原总控入口指向 `app-workflow-control`；旧全局状态执行器由唯一公共控制器替代。
- 原总编排入口指向 `app-creator-workflow`；原目录中的引擎工具、领域合同、模板、项目初始化脚本和提示模板作为非入口资源保留。
- 原拷问入口指向公共 `grilling`；现有用户决定和授权不能由本地记录自动补签。
- `app-asset-workflow` 串联去 AI 味生产流程，具体制作继续使用完整专业技能。
- 五个 `app-stack-*` 维护框架、原生约束、证据类别和完整专业导航，不承担替代专业技能的职责。
- `app-domain-toolkit` 集中维护经过源字节、差异配置和依赖闭包核对的公共视觉合同、图片/补帧算法、字库及具体生产规范。原专业路径提供薄适配，不各存整份相同算法。逐项来源及适配见[公共能力清单](shared-capabilities.md)。

原自动本地提交、默认分支/worktree、推荐测试后等待用户选择、默认代理截图验收等公共策略按当前用户约束统一。领域原有输入、资源版本与技术校验保留；不将领域上下文直接当作公共 Work Item，也不运行第二套全局状态机。

## 重点专业能力

Unity 的16份原生规范、Unity Workflow Toolkit的203个配套文件及80个C#文件整体保留。原主CLI中混合的Unity所有权与工程证据校验抽为只读模块；.meta、GUID、Importer、序列化对象、共享设置与单Editor写者的检查不由通用控制器概述替代。

Cocos、Phaser、Three.js 保留帧动画、广告、图片优化、资源接入、布局、音频、数值、动态反馈和各自独有能力。领域合同中真正相同的纯模块抽成公共实现；含 Creator UUID、Phaser runtime URL、Three.js 世界视口或其他原生差异的合同继续独立维护。正式脚本使用的 test-fixtures 属于依赖，不能按名称删除。

Three.js 另保留 3D 建模、GLB 模型校验、Starter、运行时和插件管理。Cocos 与 Phaser 的 Spine 制作、图片和构建检查脚本完整保留。

Flutter保留12份原生规范、嵌套flutter-dev模板和生成脚本、布局规格校验器及全部48个夹具。原编排中的提示模板和工件映射保留；根快照工具按目标Git工作区运行，专用校验工具针对迁移后的权威路径适配。CommonJS作用域与统一依赖解析一并保留。

## 依赖与安装

专业工具共享 `app-skill-runtime` 的 Sharp、YAML、Ajv 与格式扩展，锁文件随资源分发。源包声明和锁文件的原始去向在文件清单中逐项记录。安装器分发所选栈全部专业目录和支持资源；显式执行 npm ci 准备一次工具依赖，不从开发机源目录解析模块。

外部引擎、FFmpeg、FVM、Spine、Blender MCP 等仍按专业技能检查连接和版本，本次迁移不虚构可用实例或运行结果。原生编译、实际图片显示与发布只能据真实证据报告。

## 完整性与限制

文件级摘要仅用于迁移审计，不成为产品审批一致性门。公共流程替换项有明确实际目标，未分发的源元数据有具体理由；专业能力不得以 source-only 或概述代替。共享项记录实际公共真源、专业适配、源摘要及规则块范围；相同规则不再复制维护，独有规则不能因抽公共而消失。

默认离线核对目标文件和依赖，提供 source-root 时重新读取源仓库并比较完整 Git 清单和源字节。测试中的合成图片、模型和用户消息只验证工具与控制关系，不代表真实用户确认、引擎验收或外部发布。

源仓库及所含第三方资源的许可文本、包声明与来源说明应沿用；不能仅凭一条 package 许可字段宣称所有插件或素材均可对外发布。本次不执行上传或发布。
