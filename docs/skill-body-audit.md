# 五栈正文与资源复查

日期：2026-10-27。范围包括五个来源仓库的 91 个正式技能、77 个专业模式、原生参考、脚本、模板、校验器及嵌套项目模板。具体目标和来源摘要以[迁移清单](../migration/catalog.json)及[文件账本](../migration/files.json)为准。

## 维护边界

公共能力只有 30 个可发现入口。同职责的详细规则由公共参考维护，各栈手册和资源包保留原生接口、数据字段、项目路径与真实调用。公共参考按任务和适用栈渐进读取，不把整个素材、动画或布局资料库自动加载。

本轮继续整合广告、素材生产、布局、反馈、Spine、架构、编排、拷问、Git 文件选择及领域视觉合同。Unity 文案和美术判断只共享经逐句核对的原则，保留 Unity 的阶段、组件、语言、无障碍与证据字段；Flutter 的 Widget、页面漏斗和布局工具继续独立维护。

相同的玩法职责转入同一公共章节；编排中的原子部件要求引用既有素材规则。工件仍按完整源区间和原始摘要追溯，代码围栏、表格、有序步骤、原生补充及本栈链接均纳入核对。

本轮新增 52 个公共正文主题：30 个专业参考主题、12 个编排主题、8 个领域合同主题，以及 Git 文件选择和美术质量原则。公共真源合计 114 项，其中正文 84 项、模块 26 项、素材 3 项、模板 1 项。根技能入口仍为 30 个，没有按参考主题新增入口。

## 协议与资源整理

- G0–G3 仅表示游戏生产里程碑；工作项阶段、视觉阶段、状态和命令以公共控制器实际 Schema 与运行时为准。
- 旧控制命令和批准路径改为当前控制协议；视觉领域真实使用的 `repair`、`revalidate`、`return` 分类不作为控制 CLI 命令，也不删除其数据含义。
- 旧入口元数据集中归档到 `migration/source-metadata`，保留 87 份来源的原始字节，不继续随栈安装。真实技能及来源中实际存在的嵌套项目模板资源保留。
- CommonJS 作用域仅为实际脚本生成；空资源根和重复 Unity 图片工具通过摘要保护流程清理，公共作者文件只读复用。

## 审计与验真

`npm run audit:bodies` 检查原生手册中的完整重复段落；`npm run audit:references` 无长度阈值检查实际分发的参考正文。两者提供语义审查候选，不把源码字段、目录绑定、领域枚举或公共导航误判为可任意删除的规则。

最终扫描覆盖 305 份参考，报告 38 组字面重复；其中 33 组位于领域参考，内容主要为公共规范导航、领域枚举说明及本栈 Schema 绑定提示。另外 5 组是交付协议、玩法所有权和美术检查表的导航或适配摘要。审计报告保留这些候选，不以过滤分类制造“零重复”结论。审查中发现的完整视觉准入、确认前置、场景字段和生产规则已经共享；过时的全局状态、批准和执行器叙述改为指向当前公共协议。原生合同中的真实字段、输入格式、代码与校验器接口继续保留。

10 份已无原生正文的导航参考直接并入公共目标，迁移账本仍保留来源摘要、完整段落及合并方式，不保留导航空壳。Cocos 本地服务的 Creator 补充和 Three.js 拷问差异继续保留。目录检查确认 `skills/` 下没有空目录或仅剩 `agents` 的目录；87 份旧入口元数据已归档。五栈按需安装仍各自核对公共依赖闭包和本栈资源，不借合并安装其他技术栈。

不能仅凭另一个引擎的名称判定内容错误：例如 Phaser 的 Spine 输入工具实际支持解包 Cocos 导出容器。也不能因术语相同便合并控制命令和领域数据枚举。来源缺失、摘要漂移、链接目标不等价和实际接口差异均需要重新审查。

完整性检查使用 `node scripts/verify-migration.mjs --source-root ..`。五栈安装测试核对实际资源摘要、公共章节锚点、按需入口、原生差异与可执行的本地工具；验证结果见[验证记录](verification.md)。这些检查不代表引擎、真机或显示效果验收。
