## 剩余相同文本

按相同规则扫描前后，长度至少120字符的跨栈等价段落从108组降至5组，重复字符统计从38064降至1508。扫描只统一链接和列表编号表示，不抹去原生API与参数差异，不把短导航计入正文副本。

剩余5组已逐项检查，当前没有待合并的独立正文副本：

- 2组是清理权限及执行复核的公共协议适配，由 [professional-routing.mjs](../scripts/migration/professional-routing.mjs) 单点生成，不分别维护三份规则。发布候选、证据和授权正文已进一步提升至[公共专业约定](../skills/app-creator-workflow/references/professional-conventions.md#release-candidate-evidence)。
- 3 组是帧动画命令示例、Spine 原版目录输入和 UI 校验命令。它们调用各自实际工具，保留在本栈入口；执行算法或领域合同的不同不能只因命令外观相同而删除。

没有把“零相同字符串”作为目标，也没有用目录数减少代替规则去重。后续使用 `npm run audit:bodies`，或 `node scripts/audit-skill-bodies.mjs --output <报告路径>` 复查正文回流。分类报告用于辅助维护，不能替代专业语义审查。
